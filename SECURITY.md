# Security Policy

## Supported Versions

We actively support and resolve vulnerabilities in the following versions:

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |

## Reporting a Vulnerability

If you discover a security vulnerability in SpendSense, please do **NOT** open a public issue. Instead, report the vulnerability privately by sending an email to `security@spendsense.io` (or your personal security contact email).

Please include:
- A detailed description of the vulnerability.
- Steps to reproduce (proof-of-concept scripts or instructions).
- Potential impact.

We will acknowledge receipt within 48 hours and work to resolve the issue as quickly as possible.
